# 动作参数记忆（2.1.76 / 87）

保存动作设置、使用训练中的重量/次数调整，以及保存新建或编辑后的计划时，记录最近使用的参数。后续训练、计划预览/编辑和新计划选入同一动作时，应用最近参数。已有训练记录和已完成组不重写。

按动作名及力量/有氧、自重类型区分，记忆组数、逐组重量/次数/休息、有氧目标。动作图片、视频链接、部位等继续使用当前动作元数据。已有计划的 ID、周期关联及数据库结构保持；预览和开始时覆盖旧目标值，因此同名动作在不同计划间使用最近保存的参数。

`ExerciseMemoryStore` 使用独立私有偏好保存，写入成功后更新内存状态，不依赖页面生命周期。没有历史记忆的动作沿用原有默认值。未点击保存的编辑草稿不记忆；历史记录编辑也不会改变训练目标。

界面改动：讲解入口定位底部、删除“只修改本次训练”等说明、次数加减控件数字居中、自由训练两枚图标去掉外层色块。
