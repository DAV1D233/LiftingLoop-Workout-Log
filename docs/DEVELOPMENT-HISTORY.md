中央恢复槽使用两层缓慢流动的波面、半透明的浅绿至青蓝水体和柔和反光。水位仍按本次休息进度上升；波动在接近空槽或满槽时减弱，倒计时保持在水体上方。连续水面动画只在休息期间运行，休息结束后隐藏。

长按动作的参数面板按“组数 × 重量/额外负重 × 每组次数”横向排列，组间休息单独一行。点击训练页次数或重量，工作时显示当前组、休息时显示下一组。休息期间主按钮两侧提供 −15 秒 / ＋15 秒，仅改变本次剩余休息（上限 600 秒），减少到零结束休息；调整支持回退。中央圆形恢复槽随已休息时间由下向上填充，时间调整后重新计算，结束或跳过后隐藏。休息起始时间随会话持久化，回退同时恢复剩余时间和填充进度。

训练进行页按可用高度自适应进度环、间距和主按钮，不再依靠上下滚动显示底部进度。额外负重说明可点击调整；长按动作在同一面板设置组数、次数、重量或额外负重及休息时间，一次保存与撤销，已完成组保持原记录。

添加自定义动作可设置完整训练参数、肌群/部位、图片图标和可选 B站视频链接；未选图片使用默认图标。图标从系统图片选择器导入并缩小复制到应用私有目录，无需广泛媒体权限。自定义动作独立保存到动作库，按填写的部位分组；参数、图标和视频随训练计划、草稿和当前会话保存。

Android 原生健身记录应用。此次重构重新实现了全部应用源码、页面、导航、数据访问、训练状态、主题、反馈与资源；训练进行页按用户参考图保留部件位置。首页使用暖纸色背景、绿色运动入口与橙色饮食入口，训练时切换深色界面。

安装包：[releases/fitlog-2.1.34.apk](releases/fitlog-2.1.34.apk)。Android 8.0 及以上，包名 `com.fitlog.app`，版本 2.1.34 / 45。这是 debug 签名构建，沿用本地 debug 签名。覆盖安装可以保留应用数据；不要先卸载旧版。

设置和训练准备页提供体重录入。自重动作使用体重加额外负重，例如体重 70 kg、额外负重 5 kg 时记录为 75 kg；器械动作仍使用输入重量。训练开始时保存体重快照，之后更新体重不改写历史。自定义动作的自重类型会随计划和草稿保存。小米 S200 当前支持手动录入称重结果，尚未接入自动同步；官方说明使用米家 App，见 [S200 产品说明](https://www.mi.com/tw/product/xiaomi-smart-scale-s200/)。

训练页的“回退”和系统返回键撤销上一步完成、跳过休息或参数调整；跳过休息的撤销恢复当时剩余秒数。最近 64 步撤销状态随进度保存，支持重启恢复。退出使用独立的“退出训练”入口。最后一组完成后可以继续回退，点击“保存训练”才写入历史并结束；确认保存后不再提供撤销。

## 构建

使用 JDK 17、Gradle 8.7 与 Android SDK 34。依赖版本集中在 `gradle/libs.versions.toml`，SDK 路径由 `local.properties` 指定。此工作区使用相邻 `toolchain` 目录的工具，PowerShell 命令如下：

```powershell
$env:JAVA_HOME = 'F:/vibe coding/toolchain/jdk-17.0.20.1+1'
$env:GRADLE_USER_HOME = 'F:/vibe coding/toolchain/gradle-home'
& 'F:/vibe coding/toolchain/gradle-8.7/bin/gradle.bat' :app:assembleDebug :app:lintDebug --offline --console=plain
```

生成文件为 `app/build/outputs/apk/debug/app-debug.apk`。本地调试签名优先使用 `.local/debug.keystore`，没有该文件时使用 Android 默认 debug 配置。新环境默认签名可能与现有安装不一致；签名文件不应提交到源码仓库。
