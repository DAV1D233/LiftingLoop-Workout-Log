# 上次训练安排提示

首页“今日训练”卡片、Dock“今日计划”共用入口。在没有进行中训练、今天为训练日且此前有尚未开始的有效安排时，显示底部提示：

**上次安排的训练还没开始**

接着上次练，还是按今天的安排？

- 接着上次练：显示上次计划名及动作/组数。按天循环从首次漏练的那项接续，整个周期（包含休息日）按相隔天数顺延；按周循环只替换今天，之后仍按星期安排。
- 按今天安排练：显示今天计划名及动作/组数。跳过此前安排，之后不顺延。
- 暂不开始/关闭/返回：不改安排，下次仍可选择。

选择后先进入已有训练准备页。仅真正启动训练后保存决定；取消准备、取消倒计时、体重未填写、计划已删除均不会推进周期。准备期间跨天或安排改变时，开始前拒绝过期选择并提示返回。

进行中的训练优先直接恢复；今天为计划休息日不弹提示。已开始的安排即算已处理，不要求达成全部组数。开始决定持久保存，重开不会重复追问；现有历史记录还可排除相应日期同名计划。按周替换的当天计划保存在偏好中，首页继续显示该计划。

升级后的首次打开才建立追踪起点，不追溯升级前多年漏练。重新保存训练周期会建立新起点；原历史记录不修改。无新依赖，无 Room 结构迁移。按天顺延沿用现有周期起点，周期预览按新起点计算。
