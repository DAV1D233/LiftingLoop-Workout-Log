# 动作管理（2.1.77 / 88）

入口：首页加号 → 动作管理。沿用白底、中性浅灰卡片和薄荷绿操作色，提供名称/部位搜索、器械/自重/有氧筛选，右上角新增、点击卡片或铅笔编辑、垃圾桶删除。

新增和编辑复用动作参数表单，支持名字、类型、多部位、图片、逐组重量/次数/休息、有氧目标及讲解链接。名字不能与动作库其他条目重复。编辑后同步最近参数记忆，未来在新计划中选入时使用最新设置。

内置和自定义动作统一管理。内置编辑以本地覆盖条目保存，保持原列表位置；删除内置动作用持久移除标记，重开应用不会重新出现。重命名不会留下两个库条目。动作删除需确认，仅影响动作库及后续选入，不级联删除已有计划、当前训练或历史记录。已有计划保留动作快照；参数记忆规则仍按动作名及类型生效。

实现涉及 `CustomExerciseStore`（条目/移除标记同次偏好提交）、`AppViewModel.exerciseLibrary`（统一响应式动作库）、`ExerciseManagementScreen`、复用 `CustomExerciseSheet`、新计划动作列表及首页导航。没有数据库迁移或新增依赖。
