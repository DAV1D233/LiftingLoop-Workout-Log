# 食物标签

新增和编辑自定义食物时，可从内置及自定义食物已有的标签中选择，也可输入新标签。每种食物使用一个标签，沿用原有 category 字段和分类筛选，无数据库迁移或新依赖。

新标签去除首尾空白、合并连续空白，限制20字，禁止空名称及筛选入口保留字“全部”。同名标签自动复用。新标签随食物一起保存，取消食物编辑不会写入标签。编辑后，当前购物清单的对应食物也更新，历史饮食记录保留原始数据。

保存后在“自定义”食品库中按标签筛选；食品来源（家常、肯德基、麦当劳、自定义）与标签相互独立。删除最后一个使用某标签的自定义食物后，该标签不再作为独立空分类保留。
