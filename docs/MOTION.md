# FitLog 动效约定

用户于 2026-10-18 确认：以后所有动画遵循“从哪来，回哪去；可打断”。

- 展开和收起共用空间路径与锚点，关闭沿进入路径返回，不用无关方向的退场替代。
- 动画由当前状态驱动。中途改变目标时从当前可见进度继续，避免重置起点、闪跳或排队等待旧动画结束。
- 视觉退场与交互状态分离。取消后立即释放遮罩、指针、焦点和业务状态，退场画面不得拦截页面触摸。
- 动画结束回调只清理仍属于本次过渡的状态，不能覆盖后续打开、导航或选择。
- 尊重应用减少动态效果及系统动画设置，不为展示效果擅自关闭无障碍偏好。

2.1.57 首先应用于 HomeDock：菜单文字与竖线共用一个可反向的 Animatable；收起中重新点击同一入口从当前位置继续展开，切换其他入口取消旧过渡并以新入口为锚点。收起的菜单保留 Compose 绘制，选项点击和全屏取消层立即移除，关闭待执行的滚动并保留只读滚动位置；不再使用整块 GraphicsLayer 快照的下移退场。图标缩放、加号旋转及材质回弹的两个方向均使用可中断弹簧。

此约定适用于后续新增或修改的动画，不代表所有已有动画已完成审计。减少动态效果开启时直接切换状态。真实设备上的快速开关、切换菜单及退场期间首页点击仍需实机验收。

## 2.1.65：统一生动动效

- 设置 → 动效与辅助功能新增“生动动效”，默认开启，写入现有私有偏好 `lively_motion`；不改变此前的减少动态效果或声音、振动设置。减少动态效果、系统动画关闭与应用退到后台优先停用装饰动效。关闭总开关不改变玻璃材质与业务状态。
- 共用实体按钮、文字按钮、图标、筛选、参数表面、可点卡片与操作行复用真实 `MutableInteractionSource`，按下压缩 1.5%–6%，松手弹簧恢复。没有新增触摸层，原圆角裁切与命中范围保留。卡片/分段的选中底色短暂过渡，滑块拖动直接跟手，松手弹簧就位。
- 导航进入从右侧轻移入，返回沿原路径退出；已有首页 Dock 的反向收起、加号旋转与选中反馈接入同一有效动效策略。历史展开/收起、日历模式、日期选中、参数滚动与重量示意也遵循关闭/减少策略。
- 训练完成转场只在 `SessionSummary` 存在时开始，即记录保存成功后。使用训练页实测大环位置：先放大至约 1.28 倍并以径向渐变绘制柔光，再移向完成页圆标；同时进行一次有限彩带爆发，完整训练 36 片、提前结束 18 片，最长 1.5 秒。勾号由两段线顺序生成，关闭动效直接显示完整勾号与总结。
- 彩带仅为 Canvas 绘制，无触摸、焦点、截图、定时业务回调或保存职责。完成页操作无需等待转场结束；返回离开自动取消，关闭动效/退到后台立即结束装饰，不重播。重建窗口用 `rememberSaveable` 防止重复庆祝。
- 系统原生输入、滚动惯性及 Material 弹窗/控件固有状态反馈保留，不把它们当作新增庆祝效果重复叠加。开关控制本次新增及接入的应用装饰动效，系统自身动画仍由系统设置管理。
- 没有新增运行时依赖。编译、Lint 与领域/数据库回归用于检查兼容和业务；当前无连接设备，不能据此宣称帧率、触摸或视觉验收通过。后续真机重点检查：完成后立即返回、转场时打开记录、旋转/后台恢复、主开关与减少动态效果组合、快速切换菜单和实体按钮裁切。

## 2.1.69：休息结束提示与成绩卡片

- 内圈只为正在进行的组显示白色；休息时保留完成组蓝色和未开始组暗色。自然结束休息或点击跳过后，当前组条沿暗色→白色→暗色→白色进行两次柔和出现，随后保持白色，中央显示组号。有氧提示后回到本段计时。减少动态效果/关闭生动动效时不闪动。
- 上述提示不改变计时、休息结束时间、已完成组、撤销或保存流程；离开/状态变化取消过时提示。最后三秒的 3/2/1 继续显示在中央小圈安全范围内。
- 完成页与本次训练详情复用成绩卡片；庆祝大环收拢位置使用新卡片内勾号的实测位置，不再使用固定圆标半径。
- 分享由用户点击触发，在私有缓存 `shared-workouts/` 生成 PNG，再打开 Android 系统分享面板；不自动发送。只通过专用 FileProvider 授予选中图片临时读取权，没有公共存储权限、相机权限或网络上传。超过七天的旧分享缓存可自动清理。真实分享接收、字体放大、窄屏及视觉动效仍需设备验证。

## 2.1.71：首次长按的手势生命周期

- 全屏拖动观察节点固定放在 HomeScreen 的内容与 Dock 共用父级，不再在菜单打开时插入覆盖层的指针节点。观察节点关闭菜单时不消费任何事件，不遮挡首页控件。
- 每次按下时先判定是否已展开菜单、起点是否在入口范围内；属于入口的长按从按下到松手始终由原 orbitGesture 处理，不能在半途中被全屏选择接管。回调通过稳定 DockDragController 更新，不因菜单动画重组更换指针监听。
- 首次长按上滑不再要求 presented 与菜单一致或菜单行完成测量。已测量的入口提供坐标，尚无行高时采用 52dp；菜单排版后继续使用真实行高。原始拖动选择、顶端限制、松手确认、取消和反向动画保留。
- 真机重点：强行停止再启动后不先点按，分别长按锻炼/饮食/添加并上滑松手；空白点击取消后再长按；点击展开后从其他屏幕位置上滑；多指/系统返回取消；减少动态效果开启/关闭；菜单关闭后首页计划/日历/设置可点。当前 adb 无设备，尚未执行此组实机检查。

## 2.1.72：统一 Dock 输入所有权与完成流程

- 2.1.71 真机复现：冷启动后长按能展开且上滑能放大选项，UP 后回首页，没有执行所选导航。将观察层挪到父节点仍不足以解决圆形入口内独立监听的取消/交接。
- 移除入口自己的 orbitGesture，改由 HomeScreen 的唯一稳定父级节点处理从 DOWN、长按等待、MOVE 到 UP 的完整流；保持根坐标，即使手指在长按等待期间离开 64dp 圆圈也不丢弃操作。按钮只保留键盘与读屏语义、压缩/高光绘制。起点不在按钮的触摸仍交给原子控件，只有已展开菜单的竖向拖动超过阈值才接管；多指/取消不确认。
- 三个入口分别强停后重启，第一次操作直接长按上滑松手，验证运动日历、记录饮食、训练计划页均可进入；滑回圆圈取消、点空白关闭后设置可点击，也已验证。未更改手机的减少动态效果选项。
- 最后一组的检查点写入后，在同一 sessionLock 下走 saveSessionLocked，先保存 Room，再清空活动检查点并发布总结。失败保留已完成状态供重试，唯一 sessionKey 避免重复记录。恢复时发现全部完成检查点则补存。原提前结束/空训练规则不变。
- 完成画面恢复深色简洁勾号、标题、摘要与“查看运动详情”/“回到首页”。详情按钮才打开原逐组海报与分享编辑。庆祝收拢仍使用勾号实际 bounds，遵循动效设置。
- WorkoutSaveValidation 为无第三方测试依赖的 Android Instrumentation，验证真实生产 ViewModel/Room：非末组、末组自动保存、连点幂等、有氧指标、活动检查点清除/恢复、提前结束、空训练、休息阻挡。使用随机隔离 Context、数据库/偏好与文件目录，并在写测试数据前验证 canonical 数据库路径，绝不在用户历史中造记录。
- WorkoutValidationActivity 仅 debug 变体、不可导出、无 ViewModel/账号同步；只用于渲染真实完成页与详情 composable 的仪器测试。release 不包含该 Activity，不是产品入口。
- 补充使用未变形的 onSizeChanged 行高计算选择距离，避免展开/选中缩放改变手势步幅。
- 本轮最终验收：编译、Lint（0 错误、2 项既有未使用资源警告）、341 项领域/3918 项分享排版与 Gaussian 断言、SQLite 回归通过。Android 16 真机隔离 Instrumentation 19 项断言通过（INSTRUMENTATION_CODE -1），包含三入口新组合树首次长按拖动松手导航、等待长按时提前离开圆圈，以及自动保存和简洁页→详情点击链路。
- 运行方式：构建并覆盖安装 debug APK，构建/安装 debug AndroidTest APK，执行 adb shell am instrument -w -r com.fitlog.app.test/com.fitlog.app.WorkoutSaveValidation。测试结束后已移除本轮新增的测试包并重新打开正常首页；测试目录位于专用随机私有缓存，测试记录未写入用户数据库。真实业务 debug 版本 2.1.72 / 83 保留在手机，未另行发布下载包。
