# 训练结束页与照片海报（2.1.70 / 81）

- 结束页采用白色通栏布局，包含动作名称、每组重量/次数；保留保存后的庆祝与勾线动画。详情页复用同一完整记录，去除重复的动作卡片。
- “编辑 / 分享训练卡片”打开应用内原生全屏编辑器，支持相机、相册、海报标题、手机全屏/9:16、文字居中/靠下、文字背景模糊。点击海报隐藏工具和系统栏，再次点击/返回键恢复编辑。长记录可翻页，导出时分享全部页面，不丢组。
- 预览和导出共用 Canvas 文档：按文字实际高度分页、重复跨页动作标题；力量每行最多三组，有氧展示时长、距离及存在的计次/泳姿/池长。字体单独绘制。未添加新鼓励到训练之外的页面。
- 照片仅保存在专用私有缓存，导出为 PNG，使用 FileProvider 限定的分享目录和临时读取授权打开系统分享面板。用户自行选择接收方；不自动上传。拍照委托系统相机，不申请相机/相册存储权限；相册使用 GetContent。
- 导入检查文件大小（80 MB）、按采样限制解码边长，修正 EXIF 的八种方向；重编码去掉原始 EXIF。相机取消清理临时文件。相片、海报缓存后续使用时清理超过七天的文件，用户仍可通过 Android 应用设置清除缓存。
- 模糊是照片缩小到 270 像素宽后的可分离 Gaussian 卷积，再在文字区域渐入；不是对文字或全屏 UI 模糊。背景叠加深色渐变保证亮照片上的可读性。工作仅在编辑变化时发生，取消编辑会取消后台工作；Android 8 起可用，无着色器要求。
- 导出为 1080 像素宽，逐张生成、写盘、释放，避免同时持有全部大图。Compose 正在显示的预览 Bitmap 交给 GC，避免 RenderThread 使用已回收图像。
- EXIF 读取显式引用 androidx.exifinterface 1.3.7（Apache-2.0），该版本此前已通过 Coil 2.6.0 存在于运行时，未增加新的运行时库或更换构建栈。
